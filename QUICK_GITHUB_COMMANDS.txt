OPTION 1: AUTOMATED (EASIEST)
================================================================================

Just double-click this file:
    push_to_github.bat

It will automatically:
- Initialize Git
- Add remote repository
- Stage all files
- Commit changes
- Push to GitHub

================================================================================
OPTION 2: MANUAL COMMANDS
================================================================================

Open PowerShell or Command Prompt in this folder and run:

1. Initialize Git:
   git init

2. Add remote:
   git remote add origin https://github.com/KishoreShyam/Health-Sight-AI.git

3. Stage files:
   git add .

4. Commit:
   git commit -m "Initial commit: Health Sight AI"

5. Push:
   git branch -M main
   git push -u origin main

================================================================================
IF REPOSITORY ALREADY HAS CONTENT
================================================================================

If you get an error about existing content:

   git pull origin main --allow-unrelated-histories
   git push -u origin main

Or force push (overwrites remote):

   git push -u origin main --force

================================================================================
AUTHENTICATION
================================================================================

When prompted for password, use Personal Access Token (PAT):

1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Select scope: "repo" (all)
4. Copy the token
5. Use it as password when pushing

================================================================================
VERIFY PUSH
================================================================================

After pushing, check:
https://github.com/KishoreShyam/Health-Sight-AI

You should see:
✓ All Python files
✓ Documentation files
✓ README.md
✗ No large data files (excluded)
✗ No model files (excluded)
