# 📊 OncoVisionAI - Dataset Guide

## Overview

This guide explains how to obtain and prepare real medical datasets for OncoVisionAI. The system currently uses synthetic data for demonstration, but can be trained on actual medical imaging datasets.

## Supported Cancer Types

1. **Skin Cancer** (Melanoma, Basal Cell Carcinoma, etc.)
2. **Oral Cancer** (Oral cavity lesions)
3. **Cervical Cancer** (Pap smear images)

## Public Medical Datasets

### 1. Skin Cancer Datasets

#### HAM10000 (Recommended)
- **Name**: Human Against Machine with 10,000 training images
- **Size**: 10,015 dermatoscopic images
- **Classes**: 7 types of skin lesions
- **Source**: https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/DBW86T
- **Paper**: Tschandl et al., "The HAM10000 dataset" (2018)

**Download Instructions**:

**Format**:
- Images: JPEG (600×450 pixels average)
- Metadata: CSV with diagnosis, age, sex, localization
- Labels: 7 classes (can be grouped into benign/malignant)

### Step 3: Convert to OncoVisionAI Format

Create a script to convert your dataset:

```python
import pandas as pd
import shutil
from pathlib import Path

# Example for HAM10000
def convert_ham10000(source_dir, target_dir):
    """Convert HAM10000 to OncoVisionAI format"""
    
    # Load metadata
    metadata = pd.read_csv(f"{source_dir}/HAM10000_metadata.csv")
    
    # Map diagnoses to binary labels
    malignant_types = ['mel', 'bcc', 'akiec', 'scc']  # Malignant
    benign_types = ['bkl', 'nv', 'df', 'vasc']  # Benign
    
    image_data = []
    
    for idx, row in metadata.iterrows():
        image_id = row['image_id'] + '.jpg'
        diagnosis = row['dx']
        
        # Determine label
        if diagnosis in malignant_types:
            label = 1  # Malignant
        else:
            label = 0  # Benign
        
        # Copy image
        src = f"{source_dir}/images/{image_id}"
        dst = f"{target_dir}/raw/images/{image_id}"
        shutil.copy(src, dst)
        
        # Store metadata
        image_data.append({
            'image_id': image_id,
            'label': label,
            'original_diagnosis': diagnosis,
            'age': row.get('age', 50),
            'sex': row.get('sex', 'unknown'),
            'localization': row.get('localization', 'unknown')
        })
    
    # Save converted metadata
    df = pd.DataFrame(image_data)
    df.to_csv(f"{target_dir}/image_metadata.csv", index=False)
    
    print(f"✓ Converted {len(df)} images")
    print(f"  Benign: {(df['label']==0).sum()}")
    print(f"  Malignant: {(df['label']==1).sum()}")

# Run conversion
convert_ham10000('path/to/ham10000', 'data')
```

### Step 4: Generate Clinical Data

Since most image datasets don't include clinical features, generate synthetic clinical data correlated with labels:

```python
from src.data_preprocessing import CancerDataPreprocessor

# Load image metadata
import pandas as pd
image_df = pd.read_csv('data/image_metadata.csv')

# Generate clinical features
preprocessor = CancerDataPreprocessor()
clinical_df = preprocessor.generate_clinical_data(
    num_samples=len(image_df),
    image_paths=image_df['image_id'].tolist(),
    labels=image_df['label'].tolist(),
    output_path='data/clinical_data.csv'
)
```

### Step 5: Verify Dataset

```python
import os
import pandas as pd

# Check files
clinical_df = pd.read_csv('data/clinical_data.csv')
print(f"Clinical data: {len(clinical_df)} rows")
```


## Ethical Considerations

### Data Privacy
- **De-identification**: Remove all patient identifiers
- **Consent**: Ensure proper consent for research use
- **Compliance**: Follow HIPAA, GDPR regulations
- **Anonymization**: Hash or remove metadata

### Data Quality
- **Expert Validation**: Images should be verified by dermatologists/oncologists
- **Balanced Dataset**: Ensure representation across demographics
- **Quality Control**: Remove blurry, mislabeled, or low-quality images

### Bias Mitigation
- **Skin Tone Diversity**: Include all Fitzpatrick skin types (I-VI)
- **Age Distribution**: Represent all age groups
- **Geographic Diversity**: Include data from multiple regions
- **Equipment Variation**: Images from different cameras/devices

## Custom Dataset Creation

If you have access to a medical institution:

### 1. Data Collection Protocol

```
Patient Consent → Image Capture → Clinical Form → Quality Check → De-identification
```

### 2. Image Capture Guidelines

- **Resolution**: Minimum 1024×768 pixels
- **Lighting**: Consistent, diffuse lighting
- **Distance**: Standardized camera-to-lesion distance
- **Angle**: Perpendicular to lesion surface
- **Focus**: Sharp, in-focus images only

### 3. Clinical Data Form

Required fields:
- Patient age
- Symptom duration (months)
- Family history of cancer (yes/no)
- Pain score (0-10)
- Lesion size (mm)
- Location on body
- Previous treatments

### 4. Annotation Guidelines

- **Two-stage review**: Initial screening + expert verification
- **Inter-rater agreement**: Kappa > 0.8
- **Ambiguous cases**: Exclude or mark for special handling
